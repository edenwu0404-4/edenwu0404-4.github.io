隐私政策 / Privacy Policy

更新日期：2026年10月27日

1. 应用及运营者

Nordic Trade Lab 的 Nordic Intelligence 是个人自用的 北欧商业新闻研究与邮件日报工具。 运营者为 GitHub 用户 edenwu0404-4。 当前正在进行配置与连接验证，尚未启用自动发送。

2. 访问的数据及用途

应用仅申请 gmail.send、openid 和 email 权限： gmail.send 用于经用户批准后发送日报； openid 和 email 用于核实实际授权账号身份及邮箱地址。 本应用不申请读取、修改或删除收件箱邮件的权限。

本机程序处理用户指定的发件地址、唯一收件地址、 日报正文和发送状态。公开新闻研究与 Gmail 身份凭据分开处理； 不将 OAuth 令牌提供给 AI 模型或放入研究提示词。

3. 存储与保护

OAuth 登录由用户在 Google 页面完成，本应用不收集 Google 密码。 授权码和短期令牌在本机内存中处理； 必要的长期凭据及账号绑定信息保存于 macOS 钥匙串。 凭据不写入公开网站、Git 仓库、日报或普通日志。 本地报告可能保留邮件地址、审核结果和不含凭据的错误状态。

4. 对外传输与第三方服务

授权、令牌交换和邮件发送需要与 Google 服务通信； 实际发送后，邮件正文和地址由 Google 按其政策处理。 本应用不出售 Google 用户数据，不将其用于广告， 不将 Google 身份数据或凭据用于训练通用 AI 模型。 邮件只发送到用户明确指定的地址。

本公开网站由 GitHub Pages 托管，不提供 OAuth 登录、 凭据上传或邮件发送功能。托管服务可能按自身政策处理 访问日志等技术信息；本站未主动嵌入统计或广告脚本。

5. 保存期限、撤销及删除

刷新令牌仅为持续授权目的保存，直至用户删除、 重新授权或令牌失效。用户可在 Google 账号的第三方连接管理中 撤销授权，并通过 macOS 钥匙串管理删除本应用的凭据。 撤销授权不会自动删除已发送邮件或本地历史报告， 这些资料需由用户自行管理。

6. Google 用户数据使用承诺

本应用使用及向其他应用传输从 Google API 获取的信息时， 将遵守 Google API Services User Data Policy， 包括其中的 Limited Use 要求。

Google API Services User Data Policy

7. 联系与变更

如有隐私问题，可通过 GitHub Issues 联系运营者。该渠道公开，请勿提交密码、令牌或私人邮件。 如数据处理方式发生变化，应先更新本政策； 涉及新增权限时须另行取得用户授权。
